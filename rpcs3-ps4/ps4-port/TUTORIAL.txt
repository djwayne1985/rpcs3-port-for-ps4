========================================================================================
0. WHAT YOU NEED
========================================================================================
- PS4 (Fat, Slim or Pro) unlocked with GoldHEN.
- The emulator file: RPCS3_PS4_NATIVE_x.xx_....pkg
- A PC (to download the PS3 firmware and prepare the games).
- A pendrive or external hard drive formatted in exFAT (recommended) or FAT32.
  Attention: FAT32 does not accept files larger than 4 GB, so for ISOs
  large ones use exFAT. An HD formatted by the PS4 as "storage
  extended" DOES NOT work (it is encrypted by the system).
- Your own PS3 games (disc, ISO, folder or PKG). The emulator does not
  comes with games, firmware or licenses.

IMPORTANT: the emulator never updates the PS4 system. Never update the
firmware your PS4 yourself if you want to keep unlocking.

========================================================================================
1. INSTALL THE EMULATOR ON PS4
========================================================================================
1. Copy the .pkg file to the pendrive (root) or to /data/pkg on the PS4
   (by FTP from GoldHEN).
2. On PS4, open GoldHEN: Debug Settings
   > Package Installer, and choose .pkg.
3. Once installed, the "RPCS3 PORT FOR PS4" icon appears on the screen
   PS4 homepage. Open it.
To update to a new version, just install the new .pkg of the same
way: your settings, saves and caches are maintained.

Folders by FTP from GoldHEN
- BEFORE SENDING FILES VIA FTP: open RPCS3 on PS4 once. In
  first opening it creates the /data/rpcs3 folder and all the
  subfolders (games, pkgs, raps, import, patches, custom_configs, data,
  data/redump, exdata, keys, dev_hdd0...) already released for FTP.
- Do not create these folders by hand in FileZilla before then and do not copy
  an entire rpcs3 or dev_hdd0 folder from another PS4 or PC: folders
  created by FTP are blocked for the emulator ("No
  write permission to ...", PKG does not install or the game does not open).
- If this has already happened: leave the FTP server ON and open the
  RPCS3 again. It fixes the permissions by itself when opening (it may take
  up to about 1 minute once; with many folders "RPCS3:
  releasing N folders and files locked by FTP, please wait...").
  A cache folder that cannot be repaired is set aside and
  recreated (the game compiles again once); games, PKGs, licenses,
  patches and saves are never moved.
- With FTP turned off, RPCS3 shows a warning on XMB with the folders
  blocked. You can also fix it using FileZilla: right click on
  /data/rpcs3 > File permissions... > numeric value 777 > check
  "Recursion in subdirectories" > OK. Then open RPCS3 again.
- If X in a game opens the window "RPCS3 dev_hdd0 folder does not accept
  recording (created by FTP): turn on FTP from GoldHEN and reopen RPCS3",
  do exactly that: the game would not be able to create his data
  (black screen). Circle back to XMB. "Start anyway" (X)
  open the game anyway, on your own: it may appear on a black screen
  or not save. Leave the FTP of the GoldHEN on whenever you open the RPCS3.

2. INSTALL THE PS3 FIRMWARE (required, only once)
========================================================================================
The emulator needs the official PS3 firmware, the same as RPCS3 on the PC.

Option A - via pendrive (easier)
1. On your PC, download the official PS3 system file (PS3UPDAT.PUP) from
   PlayStation website ("System Software Update" page
   PS3").
2. On the pendrive, create the PS3 > UPDATE folders and place the file in them:
       PS3/UPDATE/PS3UPDAT.PUP
   (it also works with the file placed on the root of the pendrive).
3. Connect the pendrive to the PS4 and open the emulator.
4. In XMB, go to the "Settings" column, choose
   "Install PS3 Firmware" and press X. The file is checked (it takes
   seconds) and the question "Do you want to install the firmware" appears?
   4.93?" (with the file version and the installed one): X (Yes) installs,
   Circle (No) cancels.
5. Wait for the "Installing..." window to finish (bar with percentage;
   needs about 550 MB free on PS4). While it's open
   XMB waits; Circle asks if you want to cancel (only until the exchange of
   files start). At the end it says "Installation is complete."; X
   closes. Okay, no need to repeat it. The next time you open the
   emulator, it checks the new firmware and deletes the copy of the previous one.

Option B - by FTP
- Copy PS3UPDAT.PUP to /data/rpcs3/ (or /data/rpcs3/import/) by
  FTP from GoldHEN and use the same "Install PS3 Firmware" item.

3. PUT GAMES
========================================================================================
Accepted formats:
- ISO from PS3 (.iso file)
- Game in folder (folder with PS3_GAME/USRDIR/EBOOT.BIN inside)
- PKG from PS3 (/DLCs games from PSN; require .rap license)

How to assemble the folders (each game in ITS folder):
- Folder disc game (disc copy):
       games/Nome do Jogo/PS3_GAME/...
       games/Nome do Jogo/PS3_DISC.SFB
  The PS3_DISC.SFB file from the disk root is mandatory: without it the
  game appears with "missing PS3_DISC.SFB" and does not open.
- PSN game in folder: name the folder after the game's TITLE_ID:
       games/NPUB30554/PARAM.SFO
       games/NPUB30554/USRDIR/EBOOT.BIN
  and import its license (see ".rap Licenses" below).
- Never copy the content of a game (PS3_GAME, PS3_DISC.SFB) directly
  inside games/: create a subfolder for it. If it happens, it
  appears with "copied directly to folder: move to a subfolder".
- ISO that has not finished copying appears as "ISO incomplete: X is missing
  GB (copy interrupted?) · copy again". Copy the ISO again (when
  the copy ends, the line returns to normal by itself). X on it opens the
  "ISO smaller than declared size" window: Circle back; "Start
  anyway" (X) opens the game, and if he reads the missing part, he stops with
  the ISO warning is incomplete. Fits a ISO that has been cut from
  purpose and it works.
- Game ISO from PSN converted to ISO (without the PS3_DISC.SFB of a disc)
  appears as "ISO without PS3_DISC.SFB: does not start": it does not open either
  on RPCS3 on PC. Use the in-game PKG.
- ISO made from a game folder by a common program to create ISO
  (ImgBurn and similar), without the PS3 disk header: since 0.39
  it opens (it is read as an unencrypted image, which is what it is).
  Even 0.38 was rejected as corrupted ISO; PC's RPCS3 also
  refusal. Since 0.40 it also opens when the PS3_GAME folder is
  inside another ISO folder, or with the names in lowercase letters.
- ISO which only has the folder of a PSN game (PARAM.SFO and USRDIR, without
  PS3_GAME) appears with "PSN game inside a ISO: install PKG
  (needs .rap license)". ISO from PS2 or PSP appears with
  "PS2 Game: Not supported by this emulator" (or "PSP Game").
- PKG game whose installation is half finished appears as "Installation
  incomplete: install PKG again."

Option A - on the PS4 itself (by FTP from GoldHEN)
- ISOs and games in folder: /data/rpcs3/games/
- PS3 PKGs: /data/rpcs3/pkgs/
  The /data/rpcs3/PS3ISO, pkg, packages, iso and
  gamez (upper or lower case doesn't matter).

Option B - on a pendrive or external hard drive (same as PS3)
On the disk (exFAT or FAT32), create these folders at the root:
   PS3ISO/ -> .iso files
   GAMES/ -> games in folder (each game with its PS3_GAME folder)
   PKG/ -> PS3 .pkg packages (PACKAGES/ and the root are also valid)
Plug in the disc on PS4: games appear alone in XMB on some
seconds (and disappear if you remove the disc). Each game shows where it comes from
(PS4, USB 1, USB 2...). In the "Network" column, below "Data Storage",
games", a line appears for each connected disc.
Saves, caches and settings are always on the PS4; nothing is recorded in
your pendrive/HD.

Install a PS3 PKG
1. In the "Game" column, choose the .pkg file and press X to install.
   Opens a window similar to the PS3, with the bar, percentage and time
   remainder; Circle cancels. If it goes wrong, the window says "It was not
   unable to complete the installation." with the reason; X closes.
2. Leave at least DOUBLE the size of the PKG free on the PS4. The emulator
   cannot query free space beforehand; if space runs out
   halfway through, the installation stops with "No space on /data (needs ~N GB
   free)".
3. PKG divided into parts (NOME_00.pkg, NAME_01.pkg...): leave them all
   the parts together in the same folder; only _00 appears in the list and it
   installs the entire package.
4. Updates: install in order (v1.01, then v1.02...). If one is missing
   previous, the message says which version the update expects.
   Update that asks for a version you don't have (e.g. disk v1.00 and a
   update v1.12 made for v1.11): the window explains and asks "Do you want
   install anyway?" X (Yes) installs, Circle (No) cancels (nothing
   is installed). Some updates already bring everything and work like this; others
   no. If the game crashes or doesn't open later, delete the folder
   /data/rpcs3/dev_hdd0/game/<TITLE_ID> of the game by FTP: the disc comes back
   opening in his version. A DLC that was in that folder is also
   deleted: install its PKG again later.
   If your disk is already the same version or newer than the update, it
   is refused (no need).
5. PKG on PS4 (GoldHEN) is not installed by the emulator.
6. While FileZilla still copies a PKG, its line shows
   "Copying..." and X warns "still copying": wait for the copy to finish
   (the list updates itself) and press X again. Each refusal says the
   exact reason (incomplete file, missing part, PKG from PS4...).

.rap licenses (DLC and PSN games)
- The license file is 16 bytes and called <CONTENT_ID>.rap, for
  example UP0001-NPUB30554_00-0000000000000001.rap.
- Put the .rap in /data/rpcs3/raps/ (via FTP) or on the pendrive
  (raps/ or exdata/ folder), loose or in a subfolder, and use the item
  "Import .rap licenses (DLC / PSN games)", at the top of the "Game" column.
  Triangle in the "Game" column > "Update game library" too
  updates the list and imports.
- Capital letters /mincase letters in the name do not matter: the emulator writes the copy
  with the name that RPCS3 is looking for. .rif files are useless (RPCS3 only
  uses .rap).

PS3 physical discs
- With the disc in the PS4 player, the emulator itself installs the game, without
  PC: see section 3.1 below.
- You can also copy the disc outside the PS4:
  a) On PC, with a compatible Blu-ray player and PS3 Disc Dumper
     (only download from the project's official page). It generates a folder
     "TITLE_ID - Name" with PS3_GAME and PS3_DISC.SFB.
  b) On a jailbroken PS3 (multiMAN, webMAN MOD or IRISMAN): "copy
     disk" generates a folder; "backup in ISO" generates a ISO.
- Copy the folder to USB:/GAMES/ or ISO to USB:/PS3ISO/ (disk
  exFAT; FAT32 does not accept files of 4 GB or more, and ISO divided into
  parts .iso.0/.iso.1 is not read: join the parts on the PC first).
- Encrypted ISO (redump format): NO longer needs a key
  manual. Press X: the "Searching for this ISO..." window searches for the
  key alone (Circle cancels) and the game opens. The key comes from a
  .ird file next to ISO (same name, any .ird of the folder or the
  subfolder ird/), from the .ird already downloaded or from the key base by
  internet (the same as the PS3 Disc Dumper; you need internet on the PS4 and the
  correct date and time). It is stored in /data/rpcs3/data/redump/
  (<TITLE_ID>.dkey and <ISO name>.dkey): the second time it opens directly.
  If the game is not in the base, the XMB says "This ISO is encrypted
  and the key is not in the base (<ID>): use a decrypted ISO". ISO and
  already decrypted folders (PS3 Disc Dumper, Jailbroken PS3) do not need
  key.
- Without internet: enter the .dkey, the .ird or a list of keys from YOUR ISO
  USB:/keys or /data/rpcs3/keys and press X again (section 3.2).
- Last resort, if the search doesn't find it: the .dkey with the SAME name
  next to ISO (Jogo.iso + Jogo.dkey), or in /data/rpcs3/data/redump/
  (Game.dkey or BLUS30443.dkey). Using the pendrive: create the redump folder in
  root of the pendrive, place the .dkey in it and use the "Import keys" item
  .dkey (USB:/redump)" from the "Network" column (below "Storage of
  games").

========================================================================================
3.1 PS3 DISK ON PS4 READER
========================================================================================
Place the PS3 game disc in the PS4 player: the emulator copies the
disc once for the PS4 and then the game opens through the list, like a ISO.
The disk is never written to or changed: the emulator only reads it.

What do you need
- GoldHEN server FTP connected. This is why the emulator reads the
  reader (the same FTP you use in FileZilla). It is in the options
  from GoldHEN: Settings > GoldHEN > Server Settings > FTP Server
  (the name may change slightly depending on the version of GoldHEN).
- The PS4 connected to a network (Wi-Fi or cable): without any network the FTP of the
  GoldHEN does not respond and the emulator does not see the reader. To read the reader
  does not need internet (section 3.2).
- Internet on PS4 (and correct PS4 date and time) the first time
  each disk: the emulator searches for the disk key alone (the same file
  .ird that the PC's PS3 Disc Dumper uses) and check if it opens the disc
  before using. Without internet, the key can come from a file of yours
  (section 3.2).
- Free space on PS4: the size of the disc plus 1 GB (one disc
  10.6 GB needs about 11.7 GB free). The screen shows how much there is.

How to install
1. Place the disc in the player and open the emulator. In a few seconds
   The line "PS3 Disc: Name (BLES01876)" appears in the "Game" column.
2. Press X. The window asks "Do you want to install this disc on your PS4?" and
   shows the size, time (an estimate), disk key, and
   free space. X installs, Circle returns.
3. Open the copy window, same as the PS3: "Copying the disc...", with the
   bar, percentage, speed and remaining time. X returns to
   XMB and copying continues (the bottom line of XMB shows the progress;
   X in the disk line opens the window again). No game opens until
   finish.
4. Circle (in the window or on the disk line) asks "Do you want to cancel the
   disk installation?": X (Yes) cancels, Circle (No) continues. What
   has already been copied and is saved: choose the disk again and install
   continues where it left off. If the application closes or the disc exits
   reader in the middle, it's the same: then she continues.
5. At the end it says "Installation is complete." (X closes) and XMB says
   "Disc installed: Name · is already in the games list."
   The game is in /data/rpcs3/games and opens with X, like a ISO, when
   his disc is in the reader (see below). In the "PS3 Disc" line,
   X also opens the installed game and Square installs it again.

To play, the disc needs to be in the player
- A game installed from a disc only opens with its disc in the player.
  PS4, as on PS3. Without the disc, the game icon becomes fainter, with
  a padlock in the middle, and the line under the name says "needs disk in
  reader."
- Insert the disk and wait a few seconds: the padlock comes out on its own (if
  before there was another disc in the player, it could take up to 1 minute; X checks
  the reader at once).
- X with the padlock opens the "Checking disk..." window and, without the
  disc, "Put this game disc into the PS4 player.", which says what
  is wrong (empty player, another game disc, FTP turned off).
  Load the disc with this window open: it changes to "Disc
  recognized." and X (Play) opens the game. Circle back to XMB.
- GoldHEN's FTP also needs to be turned on to play: that's why
  the emulator sees the disc in the reader.
- Fits any disc of the same game.
- During the game the emulator looks at the player every 3 seconds. If the disk
  leaves the player (or is exchanged for another game disc) for about 10
  seconds, the game PAUSES with the warning "RPCS3: the game disc has left the
  player and the game was paused. Put the disc back in to continue."
  Put the disc back: the game continues alone ("RPCS3: disc
  back: game resumed."). To exit without the disk: L1 + R1 + Triangle
  (returns to XMB) or PS button > Close application.
- If GoldHEN's FTP falls during the game, the game does not pause so:
  Without FTP the emulator just can't look at the reader.
- Just ask for the disc from ISO that the "PS3 Disc" line installed: the same
  file, in the same place, with the same size. In the list it appears as
  "Installed from disc · needs disc in reader." Any other ISO,
  even from the same game, it appears as "ISO from PS3" and opens without a disc, like this
  like folders and PKG.

If the key does not come (no internet, or the disk is not in the base)
- The screen warns and explains. You can install it anyway ("Install without
  key", X); the game opens when the key arrives.
- Without internet the window says "No internet: the key for this disc is still
  It's not on this PS4." and the Triangle ("Search again") searches for
  new in your files: see section 3.2.
- With the disc in the player and XMB open, the emulator tries again
  alone (1 minute later, then increasingly longer, up to 10
  minutes), also for a disc already installed without the key. No need
  from the PC or copy any files.
- Only if the disk is not in the key base: put the .ird file of the
  disk at USB:/ird, or the .dkey at USB:/keys or USB:/redump
  (section 3.2). "Import .dkey keys" copies the .dkeys from USB:/redump
  for PS4 (last resort).
- The key is stored in /data/rpcs3/data/redump/<TITLE_ID>.dkey.
  With the key, the copy is already recorded decrypted and does not need further
  nothing.

If "PS3 Disc: Turn on GoldHEN FTP" appears
- The FTP server of GoldHEN is turned off (without it the emulator does not see the
  reader). Turn it on and wait a few seconds: the line updates itself
  (Triangle > "Update Game Library" also reads the game reader
  new).

If "PS3 Disc: No Network, GoldHEN GoldHEN does not answer"
- The PS4 is not on any network, and without a network the FTP of the GoldHEN cannot
  works. Connect your PS4 to a Wi-Fi or cable network (no need
  internet) and wait a few seconds.

Good to know
- Scratched or dirty disc: if the reader cannot read an excerpt, the
  installation stops and says the sector ("The reader was unable to read a portion
  of the disk..."). Clean the disk and install again: continue from where
  stopped.
- Dual layer disks (up to 50 GB) also install; need the
  disk size + 1 GB free.
- "Test disk reader (read only)", in the "Network" column, tests the
  reader and FTP from GoldHEN and writes the result to startup.log.

========================================================================================
3.2 DISCS AND ISOs WITHOUT INTERNET
========================================================================================
The reader without internet
- The emulator reads the reader by the FTP of the GoldHEN, and the FTP of the GoldHEN only
  works with the PS4 connected to a network. To use discs, leave the PS4
  on any network (Wi-Fi or cable). To read, the reader does not need
  internet: a router without internet will do (this is still being
  confirmed in tests; If it doesn't work, send the logs).
- Without any network, the disc line says "PS3 disc: without network, FTP
  of GoldHEN does not respond", and a game installed from the disc is left with the
  padlock and the window "No network: GoldHEN's FTP is not responding,
  so the app doesn't see the reader." Connect PS4 to a network and wait
  a few seconds.

The disk key
- A PS3 disc key CANNOT be read by the PS4 reader. She
  comes from the internet (as before) or from a file made from YOUR
  disk. The emulator does not carry keys and does not download key lists.
- The key only needs to arrive ONCE. Then it is saved on the PS4
  (/data/rpcs3/data/redump) and the disk works without internet to
  always. A disk installed with the key is already recorded decrypted and
  You no longer need any keys.
- From 0.40 each pressing of the record (each manufacturing) earns its own
  own copy of the key (<TITLE_ID>-<code>.dkey): a second disk of the
  The same game no longer deletes the key from the first one.

New disk or ISO, without internet: where to put the key
- The emulator searches for the key in your files on its own:
    on the pendrive: the keys, redump or ird folders (in the root of the pendrive);
    on PS4: /data/rpcs3/keys (send FTP; the folder already exists).
  Serves: the disk's .dkey or .key file, the disk's .ird, or a list
  of text keys (.txt), one per line, with or without the game code
  (e.g. BLES01876). It can be the key or data1: the emulator tests the
  two and only use the one that opens the disk. A wrong file doesn't ruin anything.
  The emulator never deletes or changes these files.
- How to get the file from YOUR disc: on your unlocked PS3, or the
  .ird from your disc that PS3 Disc Dumper does on PC. A copy
  decrypted from the disc (done on a jailbroken PS3 or PC) doesn't even need to be
  key.

What the windows say
- In the "Do you want to install this disc on PS4?" window, without internet and without
  key, it says "No internet: the key for this disk is not yet on this
  PS4." and three outputs:
    X (Install without key): the copy is now made and the game opens
      when the key arrives (via the internet or in your file);
    Triangle (Search again): searches your files again
      (put the pendrive in first);
    Circle (Back).
- "3 key file(s) found on this PS4 and USB stick; none
  open this disk.": found key files, but none are from this disk.
- "Disc key found in <place> and saved on this PS4": found;
  can install.
- "PS4 date and time wrong: searching for the key online fails.
  Go to Settings > Date and Time.": set the date and time of the
  PS4 and press Triangle.
- Connecting a pendrive with XMB open also makes the emulator search for
  new alone (when the last search did not find the key).
- ISO encrypted without internet and without the key:
  without the key of this ISO: put the .dkey, the .ird or a list in USB:/keys
  or /data/rpcs3/keys". Put the file in and press X again.

Game installed from disc, PS4 without network
- The game continues to ask for the disc in the reader, like on the PS3, and to do so the
  emulator needs to see the reader (FTP from GoldHEN, with network). Without a network, the
  lock window says "Connect PS4 to any network (Wi-Fi or cable);
  the internet is not necessary."

========================================================================================
4. PLAY
========================================================================================
1. In the "Game" column, choose the game and press X.
2. THE FIRST time a game opens, the emulator "compiles" the game for
   PS4 ("Compiling PPU Modules" / "Building SPU Cache"). Normally
   takes 6 to 45 minutes; in large games, up to about an hour.
   It's just once; next time it opens much faster. Let it finish:
   do not close during this step, even if it appears stopped. Since 0.40
   RPCS3.log also says, every minute, "compiling the game (PPU 12
   of 88 modules, ~20 min left: do not close)" (the game is compiling:
   do not close).
   NEW VERSION: the first boot of each game in 0.40 mounts the SPU cache
   again ("Building SPU Cache"). It may take a few minutes, as in
   0.38 (Demon's Souls: about 3 to 4 minutes). Do not close: it is not a lock.
   With "Cool Mode" turned on (section 6), the opening compiles something of
   each time, like in 0.38 (the first boot of Fallout New Vegas took
   about an hour and a half like this).
   GAMES THAT INSTALL DATA: some games copy data to the HD on the
   first time, with the game's own progress bar (e.g. Fallout
   New Vegas, about 7 minutes). The game did not crash: wait for the bar
   finish. Since 0.39 the emulator no longer warns "the game looks
   stuck" while this game window is on the screen.
   (If the PS4 runs low on space or caches exceed 8GB, the
   The emulator automatically erases the cache of games you haven't opened in a long time
   time; these games compile again next time.)
   KEEP THE CACHE: do not delete the cache of a game (L1 on XMB) just because
   the first session was slow. The second already uses what was compiled;
   erase does it all over again. When updating the emulator, also do not delete
   /data/rpcs3/cache.
   Since 0.38 the second opening is much faster: "Building SPU
   Cache" loads the already compiled SPU code instead of compiling it again.
   After installing a new version of the emulator, the first time opening
   each game compiles this code once more.
   NEW SCENES THE FIRST TIME: when a scene appears for the first time
   time, the emulator is still preparing its graphics (shaders).
   Since 0.37 it draws the scene with a shader "interpreter"
   while preparing (same as RPCS3 on PC): almost nothing disappears or blinks,
   but the scene may slow down a little or slow down. From
   second time onwards the same scene is normal, as long as the cache
   be saved.
3. Many games need the tweaks and patches that PC RPCS3
   uses (without them, for example, TTT2 has black textures):
   import patch.yml from PC (section 7). RPCS3's per-game settings
   PC (config_database.dat) are already included in the package (section 6).
   Do not choose the PPU or SPU interpreter in the settings of a
   game: on PS4 it is 10 to 50 times slower (1 to 2 FPS); the emulator
   Notifies you when a game opens with it.
4. Return from the game to XMB: press L1 + R1 + Triangle together and hold
   for 1 second
   (or L1 + R1 + Options for 2 seconds).
5. Exit the emulator: PS button > Close application (the game pauses by itself
   before), or "Exit RPCS3 PORT FOR PS4" in XMB.
6. Switch games: go back to XMB and choose another game. If the next
   game does not fit in the memory left over from the previous one (the memory of the
   emulator only comes back when the application closes), or if the game
previous one ended with the GPU stopped or running out of memory, XMB shows the
   window "To play, close RPCS3 and reopen." Close fur
   PS button > Close application and open the emulator again: the game that
   you chose opens by itself after a 5 second bar (X opens
   Right away, Círculo cancels it and stays at XMB).

Shortcuts about a game on XMB:
   X start/install
   Square settings of this game
   R1 patches for this game
   R2 cheats for this game (section 7.1)
   L1 clear this game's cache (force recompile)
   Triangle options: folders (section 4.1) and "Update library
            games" (updates the list, as Triângulo did before)

========================================================================================
4.1 FOLDERS IN XMB (AS ON PS3)
========================================================================================
In the "Game" column you can group games into folders, like XMB on PS3.
Deleting a folder NEVER deletes any game: the games only return to the
list.

Triangle in the "Game" column = Options

9. PERFORMANCE TIPS
========================================================================================
- PS4 Pro: activate Turbo Mode in Settings > System > Turbo Mode
  (Boost Mode). It's the biggest gain there is: the CPU goes from ~1.6 GHz
  to ~2.1 GHz (about 31% more) in all games. If your Pro
  is without it, the emulator warns you when opening the first game, and
  "System Information" shows the measured clock. Turbo Mode also
  heats up the console a little more. PS4 Fat and Slim do not have Turbo Mode.
- In Minecraft-type games, decrease the render distance.
- Keep a few GB free on your PS4 (the emulator warns you if space is running low).
  running out).
- Very heavy PS3 games run with low FPS on the PS4 processor:
  the PS4's CPU is several times slower per core than a PC's.
  Light and medium games can run well; heavy games (e.g. God of War:
  Ascension in fights, Wolverine, races like Wipeout and Sonic) are
  around 5 to 15 FPS in heavy scenes, even with Turbo Mode and
  the recommended patches (except without Turbo Mode).
- Import patch.yml (or use "Download patches from RPCS3"): many games
  depend on PC patches. PC game settings
  (config_database.dat) are already included in the package.
- Chopping sound in heavy games: it is usually the emulated game that does not
  can produce the sound in time. Try "Seamless Audio" at
  "Automatic" (section 6): the sound is continuous, a little slower. In
  0.40 it is turned off, as in 0.38. Some games (Rango, God of War
  Ascension, inFamous) are also less noticeable with "News in this game:
  0.39" audio (section 6). Leave "Enable buffering" on: no buffering
  Sound may skip after loads and pauses.
- "Frame Skip": some games refuse to skip frames,
  and it can crash the movies of some games (it's the main suspect of
  God of War Ascension movie stopped). If a movie freezes, turn it off and
  test again.
- Video driver shader cache: since 0.40 it has been turned off, as
  until 0.38 (it used thread slots that games needed). For
  test: create /data/rpcs3/mesa-cache.flag and open RPCS3 again; to
  The second time a game is opened it compiles less (the shaders are in
  /data/rpcs3/cache/mesa, up to 512 MB).

9.1 TEMPERATURE AND VENTILATION
========================================================================================
- The PS4 won't let apps read the temperature sensor (the reading
  returns with error on all tested consoles, Slim and Pro). By
  This means the emulator cannot measure the temperature or pause the game
  by heat.
- The one who protects the console is the PS4 itself: it speeds up the fan, it shows
  the console warning too hot and shuts down before it gets damaged.
- What really helps: 10 to 15 cm free space around the air vents;
  no closed rack, cloth or rug underneath; clean the dust from
  air inlets and outlets (compressed air); cooler environment. Console
  old and very noisy: internal cleaning and thermal paste with a
  technical.
- "Cool mode (less heat)" in RPCS3 Settings reduces the
  CPU wasted for nothing (some games lose a little FPS, more in areas
  new).
- The emulator never changes the fan, clock, power or
  PS4 system.

10. IF THERE IS A PROBLEM
========================================================================================
- The error message appears on the screen and again at the next start.
- Records of the last 8 sessions are in
  /data/rpcs3/log/history/0 to 7 (startup.log, RPCS3.log, mesa.log,
  fatal.txt). Send these files to whoever will help you: ALWAYS
  startup.log together with RPCS3.log and mesa.log from the same session (only the
  RPCS3.log is not enough). Copy logs only after closing RPCS3
  (PS button > Close application): a log copied with the emulator open
  comes cut.
- If the screen stops, wait 1 minute before closing with the PS button. Se
  comes "RPCS3: the game has frozen in the video; hold PS and close the
  application.", close it using the PS button and send the logs.
- "The emulated game crashed (invalid memory access...): returned to
  menu": the game stopped due to an error within the emulator and XMB returned
  alone. You can open another game without closing the application; send the

- If the GPU stops responding, the game closes and returns to XMB; in

    level 2: also without online, with 1 compilation thread and without the

      reason was lack of threads, PC adjustments continue: they do not
      waste threads and fix graphics);
    level 3: also without the high resolution timer and with "Async" shaders
      Recompiler" without the interpreter.

  valid instantly (from 0.40).
  The level is valid for the next 8 openings of the game; if the game works
